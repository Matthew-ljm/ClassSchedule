# 课程表进度条 更新日志
## v3.2.0 (2026-10-17)

### 新增
1. **全新「触发器规则」系统**：class‑over 从单一“自动下课”升级为可自定义的多规则弹窗提醒引擎
   - 支持多条规则，按列表顺序从上到下匹配，可通过「上移 / 下移」调整优先级
   - 每条规则独立配置：触发延迟 `wait_time`、触发当前课程名单、触发下节课程名单（留空表示不限课程）
   - 三种窗口节点：两按钮选择窗、进程清理窗、单按钮提示窗，每种窗口每条规则最多一个
   - 窗口节点支持 `id` 与 `jump_to` 跳转，可编排“提示 → 清理 → 完成”等多步流程
   - 按钮与窗口支持动作：无动作 / `destroy` / `sleep N` / 手写系统命令（自动保存为 `cmd:` 前缀）
   - 按钮支持“等待结束后重新弹出”，重弹次数可设（0 = 无限次）
   - 标题与按钮文字支持 `$$` 占位符，显示时自动替换为剩余倒计时秒数
   - 标题、按钮的背景色与文字色支持可视化拾色
2. **触发器规则图形化编辑器**：完整图形界面，支持规则添加 / 复制 / 删除 / 加载模板、节点增删、跳转校验、颜色格式校验，无需手写 JSON
3. **内置规则模板**：「自动下课」「抢饭提醒」，一键加载或另存为副本
4. **本地课表图形化编辑器**：按周一至周日分页，表格编辑课程名称、开始时间、结束时间；支持增删行、格式校验、在文件夹中显示
5. **主窗口倒计时联动**：class‑over 触发时通过命名管道 `\\.\pipe\ClassScheduleCountdown` 将倒计时同步到主窗口
   - 主窗口切换为倒计时模式，进度条按剩余时间变色（绿 / 黄 / 红）
   - 倒计时自然结束或提前结束后自动恢复普通 / 教学模式
6. **系统托盘图标**：提供「设置」「退出」菜单，支持通过托盘快速打开设置或退出程序
7. **命令行参数 `--settings`**：仅打开设置窗口，便于从安装器或快捷方式直接调用
8. **单实例运行保护**：检测到已有进程时自动退出，避免重复启动

### 优化
1. **教学模式显示增强**：进行中课程名称显示在进度条上方，已上完的课程名称被进度条覆盖；显示已上课时间或剩余时间，信息更直观
2. **设置界面重构**：原“自动下课”相关项统一更名为「弹窗提醒」
3. **鼠标交互细化**：Ctrl 按住时悬停不渐变隐藏、单击不隐藏；拖拽过程中悬停自动隐藏暂时锁定，避免误判
4. **程序启动流程**：启动时自动拉起守护进程与更新组件，并同步 class‑over 状态
5. **缩短鼠标悬停渐变隐藏时间**：鼠标悬停后更快隐藏，不妨碍其他软件的使用

### Bug修复
1. 修复 `class-over.exe` 与 `class-over.lock` 文件缺失或同时存在时状态判断错误，启动时主动检测并给出修复提示
2. 修复设置界面中切换 class‑over 状态失败时设置被误保存的问题
3. 修复倒计时与教学模式切换时透明度 / 模式错乱的问题

### 兼容性与升级提示
1. 兼容 v3.1.1 的 `settings.json`，旧配置可直接使用
2. 升级后 `custom_class_over_rule` 仅包含自动下课；请打开「设置 → 弹窗提醒 → 加载默认模板」，或在规则编辑器内自行添加规则
3. 原全局 `class_over_wait_time` 仍保留为兜底值，实际触发延迟以各规则的 `wait_time` 为准
4. 仍仅支持 Windows10 / Windows11 x64，暂未适配统信 UOS
