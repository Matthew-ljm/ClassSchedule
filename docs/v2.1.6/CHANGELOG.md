# Release v2.1.6
**发布说明**
> 这是项目首个正式发布版本 v2.1.6
> ⚠️ 后续 v3.x 版本会重构UI框架，请留意版本差异

## ✨ 主要功能
- 顶部悬浮课表进度条，可视化展示当日课程，显示课程已进行/剩余时长
- 支持**云端API课表 + 本地JSON课表**双数据源，网络异常自动降级本地课表
- NTP网络校时，内置软件计时器兜底，规避系统时间不准问题
- 支持单/双周课程解析、课程自定义配色
- 窗口激活时鼠标拖拽移动窗口，支持单击隐藏窗口；窗口置顶，教学模式时自动透明，不遮挡课件
- 自动下课 `class‑over` 插件：课程结束后触发倒计时，批量清理非白名单进程
- 可选座位表扩展插件，用于教室座位排布展示
- 进程守护，程序异常退出自动重启；提供锁文件实现正常退出不反复拉起
- 一键安装脚本，支持配置开机自启，自动生成进程清理白名单

## 🖥️ 系统支持
✅ **Windows10 / Windows11 x64**
✅ **国产统信UOS系统**
> UI底层：**Pygame** 实现窗口渲染

### 🐧 统信 UOS 平台

- `ClassSchedule-v2.1.6-UOS.zip`：软件压缩包


## ⚠️ 注意事项
1. `class‑over`自动下课插件**仅用于学校公用教室电脑，家用电脑请勿随意开启**。
2. 统信系统需要自行处理开机自启动。
3. 彻底退出请使用程序内置退出快捷键，直接关闭窗口会被守护程序重新拉起。
